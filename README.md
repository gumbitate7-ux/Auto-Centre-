# Auto Centre Panel Beaters: concept website

A one-page demo site for Auto Centre Panel Beaters (5 3rd Avenue, The Hill, Johannesburg South). Every call to action sends the visitor to the workshop's WhatsApp with a message already written.

Open `index.html` in a browser to view it. There is no build step.

## What's in it

- **Damage picker (hero).** Visitors tap the damaged panels on a top-down car, choose what happened, add their car and choose how they're paying. "Send on WhatsApp" opens WhatsApp with all of that typed out, ready for them to add photos.
- **Quote links on every service** (panel beating, spray painting, bumper repair and more), each with its own pre-filled message.
- **Insurance quote button** that asks for the claim number and insurer.
- **Open/closed status** worked out in Johannesburg time from the workshop hours, with today's hours highlighted.
- **Fixed Call / WhatsApp bar** at the bottom of the screen on phones.
- **Local SEO basics**: page title, description, and `AutoBodyShop` structured data with address and hours.
- Accessible: panels work with the keyboard, focus is visible, and motion is turned off for people who prefer reduced motion.

## Files

- `index.html`: page content
- `assets/styles.css`: design (colours and type are set at the top)
- `assets/app.js`: WhatsApp messages, damage picker, opening hours
- `assets/favicon.svg`: tab icon

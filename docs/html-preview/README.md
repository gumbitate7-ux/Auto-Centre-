# CLIMORA — standalone HTML preview

These 19 HTML files are a static export of the CLIMORA Shopify theme. **Open `index.html` in any browser.** No server, internet connection or install is needed: the CSS, JavaScript, fonts and illustrations are embedded in every file.

| File | Page |
| --- | --- |
| `index.html` | Homepage |
| `shop-all.html`, `sleep-cooling.html`, `portable-cooling.html` | Collections |
| `solarflow.html`, `icesoft.html`, `frostlayer.html` | Product pages |
| `cart.html`, `search.html` | Cart and search |
| `about.html`, `contact.html`, `faq.html`, `shipping-delivery.html`, `returns-refunds.html` | Content pages |
| `privacy-policy.html`, `terms-of-service.html`, `refund-policy.html`, `shipping-policy.html` | Draft policies |
| `404.html` | Not-found page |

**What works in the preview:** navigation, the mobile menu, variant selection, add to cart, the cart drawer and cart page (saved in your browser), curated sets, search, FAQs and the sticky mobile add-to-cart bar.

**Preview limitations:**
- **Prices and variants are sample data.** On Shopify, every price, variant and stock level comes from your product data.
- Checkout, Buy Now, the contact form and the newsletter only work once the theme is installed on Shopify.
- This folder is **not** what you upload to Shopify. Shopify uses the theme folders at the repository root (`layout/`, `sections/`, `templates/`…). See `docs/LAUNCH-GUIDE.md`.
